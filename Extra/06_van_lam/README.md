# Phần Thử Nghiệm Mở Rộng - Nguyễn Ngọc Vân Lâm (N6)

Thư mục này lưu trữ các kịch bản và kết quả chạy thử nghiệm độc lập của bạn **Nguyễn Ngọc Vân Lâm**:
- `n6_chay_ca_that.py`: Kịch bản chạy thuật toán trên bài toán đường bay UAV thực tế.
- `n6_chay_kiem_nhung.py`: Kịch bản kiểm chứng tích hợp các ngách.
- `n6_kiem_nhung_K.py`: Script kiểm định embedding ngách số lượng đèn K.
- `test_n6_van_lam_woa.py`: Bộ kiểm thử đơn vị cho thuật toán WOA.
- `n6_demo_history.csv`: Dữ liệu lịch sử chạy mẫu.
